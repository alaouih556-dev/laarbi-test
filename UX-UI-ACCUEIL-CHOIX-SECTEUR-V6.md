# ALLNEEDS — UX/UI V6 — Choix du secteur sur l’accueil

- La page d’accueil affiche toujours les trois secteurs : Santé, Enseignement et Tourisme.
- Le secteur mémorisé n’entraîne plus de redirection automatique depuis `/`.
- Le secteur déjà sélectionné est simplement mis en évidence par le badge « Secteur actuel ».
- Un clic sur un autre secteur remplace le choix mémorisé.
- Après l’entrée dans un secteur, le filtrage global V4/V5 reste actif : le reste du site n’affiche que le secteur sélectionné.
- Les espaces Client restent strictement sectorisés selon leur compte.
