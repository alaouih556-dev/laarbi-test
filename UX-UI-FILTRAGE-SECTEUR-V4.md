# ALLNEEDS — Filtrage global par secteur (V4)

## Règle UX
- La page d'accueil générale est le seul endroit où les 3 secteurs peuvent être proposés avant sélection.
- Dès qu'un visiteur choisit Santé, Enseignement ou Tourisme, ce choix est mémorisé dans le navigateur.
- Les pages sectorielles n'affichent plus les boutons permettant de passer d'un secteur à un autre.
- Le header n'affiche plus « Secteurs » comme catalogue multi-secteurs : il affiche uniquement le secteur actif.
- Le footer n'affiche que le secteur actif.
- Missions, tarifs, FAQ et ALLNEEDS Accès utilisent le secteur actif.
- Le formulaire Diagnostic verrouille le secteur actif au lieu de proposer les 3 choix.
- Un retour sur / ou /secteurs redirige vers le secteur déjà choisi afin d'éviter de réafficher les trois univers.

## Objectif
Un visiteur Enseignement reste dans un site Enseignement. Un visiteur Santé reste dans un site Santé. Un visiteur Tourisme reste dans un site Tourisme.
