# ALLNEEDS principal V12
Identité bleu nuit / bleu électrique / cyan du logo fourni. Nouvelle typographie, surfaces, cartes, arrondis, boutons, en-tête et fonds appliqués globalement au site et dashboards.

Nos offres renommé Missions. Anciennes routes publiques /missions et /missions/:code redirigées vers /tarifs, qui conserve le contenu des offres. Les missions de suivi dans les espaces client/admin sont conservées.
Actions publiques Comparer les formules et Déposer un besoin retirées. Fonctionnalités internes de saisie de besoins conservées.

Le projet conserve les règles V11 (prix ALLNEEDS masqués, engagements santé, comparatif après diagnostic). Données et comptes démo préexistants conservés.

Pour connecter le SaaS séparé après publication, définir VITE_HEALTH_URL sur Vercel avec son URL, puis redéployer. Le lien est affiché dans Espace métier.

npm install ; npm run typecheck ; npm run build ; npm run dev

Ce ZIP est un projet complet, pas un installateur automatique pour remplacer un dossier existant. Sauvegarder votre projet avant copie, conserver votre .git. Ne pas remplacer le dépôt principal par le dossier Santé.
