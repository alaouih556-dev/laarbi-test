# ALLNEEDS V10 — Parcours abonnement, prix promo et limites

- Inscription : secteur + espace métier + coordonnées. Aucun abonnement ACCÈS activé automatiquement.
- SaaS : visible pour le secteur du client, verrouillé jusqu’à activation ALLNEEDS.
- ALLNEEDS ACCÈS : proposé depuis le compte et après les missions PRO/PERFORMANCE.
- Limites appliquées depuis la fiche : CONNECT 6 besoins/an, 2 simultanés ; PLUS 15/an, 3 simultanés ; PRIORITÉ 30/an, 5 simultanés.
- Prix de lancement : ancien prix barré sur toute sa largeur, nouveau prix mis en avant. STARTER : 495 DH -> OFFERT ; PRO : 8 495 -> 6 495 DH HT ; PERFORMANCE : 13 945 -> 10 945 DH HT.
- Aucun quota inventé de type "2 besoins offerts".
- Questionnaires : conservation de la vérification V7 (28 questions distinctes par secteur).
- Concierge : conservation de la portée V9, quasi-admin uniquement sur les entreprises attribuées/créées.
